# SQL Retail Sales Analysis (PostgreSQL)

## Project Overview 

This project is a PostgreSQL-based retail sales analysis built on a large-scale transactional database containing over one million records. The objective was to solve real-world business problems using SQL while applying concepts such as joins, aggregations, date functions, subqueries, Common Table Expressions (CTEs), window functions, and query optimization.

The database simulates the operations of a global electronics retailer with stores located across multiple countries.

## Database Schema

The project consists of five interconnected tables:

* Stores
* Category
* Products
* Sales
* Warranty

These tables are linked using primary keys and foreign keys to maintain data integrity and support analytical queries.

## Business Problems Solved

1. Count stores in each country
2. Total units sold by each store
3. Total transactions in December 2023
4. Stores that never received a warranty claim
5. Percentage of claims marked as Warranty Void
6. Store with highest sales in the last year
7. Count of unique products sold
8. Average product price per category
9. Total warranty claims filed in 2020
10. Best-selling weekday per store
